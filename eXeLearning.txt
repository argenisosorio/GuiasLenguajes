=========================
Guía de eXeLearning by dM
=========================

eXeLearning es un programa libre y abierto para crear contenidos educativos de
una manera sencilla.

Instalación
===========

Realizaremos la instalación en GNU/Linux Debian 11.

Nota
====

Usaremos $ para describir los comandos que se usaran con usuario regular.
Usaremos # para describir los comandos que se usaran con superusuario.

1) Descargar el .deb desde: https://exelearning.net/descargas/ Para este
ejemplo hemos descargado es el archivo intef-exe_2.6_all.deb.

2) Ejecutamos la instalación del archivo con:

# dpkg -i intef-exe_2.6_all.deb

======================
Solucion de aviso dpkg
======================

dpkg: aviso: `ldconfig' no se ha encontrado en el PATH o no es ejecutable

Ejecutar:

$ echo 'export PATH=$PATH:/usr/local/sbin:/usr/sbin:/sbin' >> /home/usuario/.bashrc

Otro error...

dpkg: atención: `ldconfig' no se ha encontrado en el PATH o no es ejecutable

Ejecutar:

$ export PATH=$PATH:/usr/local/sbin:/usr/sbin:/sbin

====================
Formatos de archivos
====================

eXeLearning permite exportar las lecciones en formato .zip, llamado también
archivo scorm, es el que se sube en la plataforma chamilo, también se puede
exportar en formato .elp, este es el formato para ser leído en eXeLearning.

==================================================================
Procedimiento para incrustar un sitio web local en eXeLearning 4.X
==================================================================

1. Crear un iDevice de tipo Texto.

2. Teniendo seleccionado el iDevice de texto ir a Menú principal > Utilidades >
Gestor de archivos. Subir el archivo .html y pulsar Insertar para incrustarlo en
el iDevice. Guardar el iDevice.

Nota: Debe darle a la opción de ver todos los archivos para poder ver el .html.
y poder adjuntarlo.

3. Guardar el archivo .elpx en el guardado de todo el proyeccto.

4. Exportar el proyecto como sitio web: Menú principal > Archivo > Exportar
como > Sitio web. Esto generará un archivo .zip con todo el contenido.

5. Descomprimir el .zip y abrir el archivo index.html en un navegador para
visualizar el sitio.

Notas:

- La carpeta exportada debe contener los siguientes archivos y directorios:
content, content.xml, html, idevices, index.html, libs, theme.

- Los recursos estáticos que necesita el .html incrustado (estilos, imágenes,
efectos) deben ubicarse en la carpeta content > resources, manteniendo la misma
estructura de carpetas y utas relativas para garantizar su correcto
funcionamiento al abrir index.html.
